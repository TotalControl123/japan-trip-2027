# Japan, March 2027

Interactive day-by-day trip plan: Tokyo → Hakone → Kyoto → Osaka, 7–25 March 2027.

**Live site:** https://totalcontrol123.github.io/japan-trip-2027/

Everything is in `index.html` (no build step). Edit the `DAYS`, `BOOK`, `PACK`, `BUDGET` and `GUIDE` arrays near the bottom of the file to change the plan, then commit — GitHub Pages updates within a minute or two.
